# 🐛 BugFlow

> Modern bug tracking and issue management platform for developers.

BugFlow is a developer-focused issue tracking system designed to help individuals and teams report, organize, prioritize, and resolve software bugs efficiently.

Inspired by tools like Jira, Linear, and GitHub Issues, BugFlow provides a clean workflow for managing the complete bug lifecycle.

---

# 🚀 Features

## 🐞 Bug Management

Create and manage bugs with:

- Bug title
- Description
- Priority level
- Category
- Status
- Assignee
- Environment
- Creation date

---

# 📊 Dashboard Analytics

Get a complete overview of project health:

- Total bugs
- Open issues
- In progress bugs
- Testing issues
- Resolved bugs
- Critical problems
